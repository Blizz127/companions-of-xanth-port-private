# Companions of Xanth v0.1.0-alpha.6

Dev menu is ON in this preview. Open it with F12, or hold Back (Select/View)
and Start together on one controller, in either order. Set dev_menu=0 in
your port config or start with --no-dev-menu to hide it; XANTH_CHEATS=0
hard-disables it.

What is new since alpha.5

- Back+Start opens the dev menu reliably on handhelds and under Steam Input.
  When Steam Input or InputPlumber mirrors a physical pad, the same chord
  arrived once per device, and each copy toggled the menu, so it opened and
  closed in the same instant. A chord on another pad within 300 ms of the
  first is now treated as the same chord.
- Controllers SDL has no mapping for, but that look like an Xbox pad, now
  work: the port gives them the standard Linux xpad layout when they connect
  (buttons 6 and 7 are Back and Start).
- Both fixes have virtual-controller regression tests.

Everything else is as in alpha.5: Finish Current Step survives missing steps,
chain-start route points are warp spots only, and the checkpoint builder lists
23 warp spots and 18 finish-step entries reaching the Region of Fire, each
offered only after your own local build and verification.

Checkpoint entries require local building and verification with the included
Python tools and your own game data. No game files, saves, artwork or fonts
are supplied. The menu uses the game's own Restore dialog, reads only verified
idle state, checks checkpoint digests, and captures player input during the
restore. Its temporary save slots never replace existing player saves and
are removed after use or shutdown.

From alpha.5 on, public releases happen at milestones and ship the Linux
package only: the port's source is maintained privately, while the
decompilation itself stays public in this repository.

Linux x86_64 requires system SDL2 and glibc 2.34 or newer. The full game is
not yet completable; see the README for current route coverage.
