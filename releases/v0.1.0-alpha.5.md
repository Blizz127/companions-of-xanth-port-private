# Companions of Xanth v0.1.0-alpha.5

Dev menu is ON in this preview. Open it with F12, or hold Back+Start on one
controller. Set dev_menu=0 in your port config or start with --no-dev-menu
to hide it; XANTH_CHEATS=0 hard-disables it.

What is new since alpha.4

- Finish Current Step keeps working when steps are missing from your local
  checkpoint list. Steps that were never built, or did not pass verification,
  are skipped and the later steps are still found. Before, one or two missing
  steps hid every step after them.
- Route points that start from one of the game's own recorded saves (the
  boundary of the Void and the desert spring) are warp spots only. Finish
  Current Step skips over them to the next real step and Finish Area ignores
  them, because the play between the previous step and that save is not on a
  recorded route.
- The checkpoint builder now lists 23 warp spots and 18 finish-step entries,
  reaching Isthmus Village, the Void, the Earth barrow and dungeon, and the
  Region of Fire up to the charcoal. Segments that end on the score panel or
  inside a conversation are dismissed first, so every checkpoint restores to
  an idle field. One failed checkpoint no longer stops the rest from building.
- Verified on the reference machine: the 8 warps and 7 finish-step entries
  from alpha.4. The newer entries are offered only after your own local build
  and sweep verify them.

Checkpoint entries require local building and verification with the included
Python tools and your own game data. No game files, saves, artwork or fonts
are supplied. The menu uses the game's own Restore dialog, reads only verified
idle state, checks checkpoint digests, and captures player input during the
restore. Its temporary save slots never replace existing player saves and
are removed after use or shutdown. The first save after a warp shows a
warning and records a line in xanth-dev-menu.log.

The menu is fully navigable with a keyboard or controller. Options include
fast-forward, screenshot, fullscreen and scanlines. F1-F10 and Backspace stay
with the game when the menu is closed. No cheats or quick save/load are
offered.

From alpha.5 on, public releases happen at milestones and ship the Linux
package only: the port's source is maintained privately, while the
decompilation itself stays public in this repository.

Linux x86_64 requires system SDL2 and glibc 2.34 or newer. The full game is
not yet completable; see the README for current route coverage.
